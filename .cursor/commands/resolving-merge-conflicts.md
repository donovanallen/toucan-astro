# Resolving merge conflicts

Resolve the in-progress git merge or rebase conflict and finish it.

Follow `.cursor/skills/resolving-merge-conflicts/SKILL.md` end-to-end. Recover
intent from commits/PRs/issues, preserve both sides where possible, do not
invent behaviour, run scoped `pnpm` checks, then complete the merge/rebase.
Never `--abort` when this command is invoked to resolve.
